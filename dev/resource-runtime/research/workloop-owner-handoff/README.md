Stage73 gets past the original sync-wait failure: the main thread is now genuinely blocked waiting for its CoreData queue. The source now loads the actual debounce word, restores the paired XNU's two borrowed Mach-name generation bits, queries real THREAD_IDENTIFIER_INFO, and verifies current-process membership using Linux's zero-signal thread check. A wrong/dead/non-thread name returns EOWNERDEAD. Domains track the actual namespace thread identity; event batches wait on an ownership epoch until release. END_OWNERSHIP by the owning thread applies even on ESTALE/IGNORE_ESTALE as the original XNU filter specifies. Wake/deletion, request coalescing and queue-state observation remain real operations.
