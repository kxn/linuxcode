# Native Bank vouchers for original iOS tools

Original libdispatch could not initialize its task voucher: fast trap70 returned KERN_FAILURE and the real MIG Bank CREATE recipe returned KERN_INVALID_ARGUMENT. The kernel now routes that trap through the original wrapper’s MIG fallback. Darlingserver compiles the complete Apple open-source Bank and ledger implementations with Linux/Darling task identity, zone initialization, real task ledgers and lifecycle glue. The server’s XNU tree is tracked inside the server repository, separately from the kernel source repository; both exact source commits are recorded.

Native tests verify real voucher ports, 128 copies/releases, 32 same-process voucher-carrying Mach messages, current-thread set/get/clear, and rejection when targeting another running thread. Another 32 messages from an exec child verify real Bank account originator/proximate PID, stable generation, audit PID-version, UID/GID and executable LC_UUID against actual child metadata. Plain task vouchers correctly reject the account-only persona-token query. No alternate-persona service is advertised.

The first native attempt incorrectly expected an account token from a task-only voucher; the fixture was corrected to Apple’s contract. The next attempt exposed the old aborting thread_set_mach_voucher stub through a live server backtrace. The replacement follows the paired XNU implementation and retains real voucher references and Bank ledger swaps. Failed controls and source history are preserved. Post-build source normalization removes only trailing blank EOF lines; exact compiled inputs remain available in the archived source history.

Original IBAgent now passes voucher initialization and reaches another event-queue request that returns ENOTSUP. This checkpoint does not complete Storyboard compilation or the Unity/UE App. Full Darwin scheduler CPU/energy charging, alternate personas, coalitions, hardware PPL and CPU limits are outside the established coverage; enabling CPU limits reports unsupported. The default installer candidate is not promoted. Only open source, UTF-8 diagnostic text and hash metadata are included; no private Apple/SDK/XIP binaries.
