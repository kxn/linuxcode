# 复用未改动文件的环境校验结果

一次运行环境组装曾重复执行约6.7万次SHA-256计算。带cProfile的原始测量为41.41秒，约29秒用于摘要计算。现在82个环境选择器共享一个文件摘要缓存：设备、inode、文件模式、大小、mtime和ctime都保持一致时复用实际计算过的摘要；原有报告中的预期摘要仍照常比较。每次缓存命中都会读取文件状态。该缓存不保存或替代任何编译、签名或运行测试结果。

完整候选的首次缓存测量22.17秒，另一进程复用后的测量4.54秒，67550次命中，文件重算零次。测量条件中，41.41秒基线带cProfile，后两次无cProfile，不能把比值当成严格微基准。优化后的运行命令、库搜索路径和源组件选择与既有原生正例逐项相同；不因此重跑无关原生测试。

九项控制覆盖首次读取、未改动命中、同长度写入并恢复mtime、原子替换、符号链接换目标、删除、另一进程复用、并发更新合并、损坏缓存回退。发现某些快速写入可能共享文件系统时间戳，因此ctime未超过一秒的文件继续重算。读取前后的文件状态必须一致，否则重试并报错。

缓存是runtime/verified-file-digests-v1.json中的可丢弃开发状态；并发发布使用短时文件锁和原子替换。删除它只会让下一次重新计算。此研究附件不包含实际缓存库、Apple二进制或SDK。payload内为源码与新配置143；reference/source-history.json及包装文件保留旧输入的精确字节。默认安装候选没有升级，完整Unity App仍未完成。
